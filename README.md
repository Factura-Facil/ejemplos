
# Ejemplos de código Fáctura Fácil
Repositorio con ejemplos de código, en lenguajes/herramientas populares, para  emitir documentos con la API Rest de factura fácil.

## Ejemplos detallados de la API `/detailed/`
En el directorio [`detailed/`](detailed/) hay 40 ejemplos JSON validados (facturas por tipo de receptor, descuentos, formas de pago, crédito en cuotas, ISC/OTI, retenciones, notas de crédito/débito, exportación y zona franca), la referencia completa de campos ([`detailed/CONTEXT.md`](detailed/CONTEXT.md)), una guía para asistentes de IA ([`detailed/AGENTS.md`](detailed/AGENTS.md)) y scripts para enviar y validar.

## Nota
Para todos los ejemplos reemplazar [UUID DE FF] y [KEY DE FF] con las credenciales proporcionadas por el equipo de factura fácil.
